# Adita Fahmi Hanif, S.T. — Structural Engineering Portfolio

Interactive editorial portfolio built with **React**, **TypeScript**, **Tailwind CSS**, and **Three.js / React Three Fiber** (`InfiniteGallery` WebGL cloth-shader exhibition).

## Local Development

```bash
npm install
npm run dev
```

Or on Windows, double-click `buka-portofolio.bat`.

## Production Build

```bash
npm run build
```

Static output is generated in `dist/` and automatically deployed to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.
